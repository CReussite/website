# Guide simplifié : se connecter à votre tableau de bord en toute sécurité

Bonjour Camille,

Votre tableau de bord admin est désormais protégé par une **double sécurité**. Concrètement,
pour entrer il faut maintenant **deux choses** et non plus une seule :

1. Votre **mot de passe** (comme avant).
2. Un **code à 6 chiffres** qui change toutes les 30 secondes, lu sur votre téléphone.

Même si quelqu'un devinait votre mot de passe, il ne pourrait pas entrer sans votre
téléphone. Vos commandes, vos factures et les informations de vos clients sont donc
beaucoup mieux protégées.

C'est exactement le même principe que votre banque quand elle vous demande un code en plus
du mot de passe.

---

## Étape 1 : à faire une seule fois (5 minutes)

### 1. Installez une application de codes sur votre téléphone

Allez dans le magasin d'applications de votre téléphone (App Store sur iPhone, Play Store
sur Android) et installez l'une de ces applications gratuites :

- **Google Authenticator** (la plus simple, recommandée)
- ou Microsoft Authenticator
- ou Authy

Cette application affichera les fameux codes à 6 chiffres.

### 2. Reliez l'application à votre tableau de bord

1. Sur votre ordinateur, ouvrez votre page admin habituelle et tapez votre **mot de passe**.
2. Un **QR code** (un petit carré noir et blanc) s'affiche à l'écran.
3. Ouvrez l'application sur votre téléphone, appuyez sur **« + »** puis **« Scanner un QR code »**,
   et visez le carré affiché sur l'écran de votre ordinateur.
4. L'application affiche aussitôt un code à 6 chiffres au nom de **C'Réussite**.
5. Recopiez ce code dans la case de votre ordinateur, puis cliquez sur **« Activer et se connecter »**.

C'est terminé. Vous êtes connectée, et la double sécurité est en place.

> Astuce : si vous n'arrivez pas à scanner le QR code, un code en lettres est affiché
> juste en dessous. Vous pouvez le taper à la main dans l'application (option
> « Saisir une clé de configuration »).

---

## Étape 2 : votre connexion de tous les jours

À chaque connexion, ce sera très simple :

1. Vous tapez votre **mot de passe**.
2. Vous ouvrez l'application sur votre téléphone et vous recopiez le **code à 6 chiffres**
   qui s'affiche.
3. Vous êtes connectée.

Une fois connectée, vous restez connectée pendant **12 heures** sur le même ordinateur.
Vous n'avez donc pas besoin de recommencer à chaque petite visite dans la journée.

> Le code change toutes les 30 secondes : c'est normal. Prenez simplement celui qui est
> affiché au moment où vous le tapez.

---

## Si vous n'avez pas votre téléphone sous la main

Pas de panique, une solution de secours existe :

1. Tapez votre mot de passe comme d'habitude.
2. Sur l'écran du code, cliquez sur **« Je n'ai pas mon téléphone, recevoir un code par email »**.
3. Un code à 6 chiffres vous est envoyé **par email** (sur l'adresse de la boîte C'Réussite).
4. Recopiez ce code et vous êtes connectée.

Ce code reçu par email est valable 10 minutes.

---

## En cas de souci

**« J'ai changé de téléphone »** ou **« J'ai perdu mon téléphone »** :
tant que vous avez accès à vos emails, utilisez la solution de secours par email ci-dessus
pour vous connecter. Ensuite, prévenez la personne qui gère le site : elle remettra à zéro
la configuration pour que vous puissiez relier votre nouveau téléphone (vous referez
simplement l'Étape 1).

**« Je n'ai ni le téléphone ni l'email »** :
contactez la personne qui gère le site. En quelques clics, elle réinitialise la double
sécurité et vous recommencez l'Étape 1 avec le QR code.

**Le code est toujours refusé ?**
Vérifiez que l'heure de votre téléphone est bien réglée sur « automatique ». Un téléphone
en retard de quelques minutes fait afficher un mauvais code.

---

En résumé : votre mot de passe **plus** un code sur votre téléphone. Une petite habitude à
prendre, pour une tranquillité bien plus grande.
